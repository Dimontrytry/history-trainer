# Проверки сборки разработки 0.1.0

Среда: Debian 13 x64; Node 24.19.0; Electron 45.2.1 с Node 24.22.1; SQLite 3.53.4. Целевая Windows-среда отдельно пока не проверена.

| Проверка | Наблюдённый результат |
| --- | --- |
| Повторная установка `npm ci` | Успешно; postinstall реально открыл SQLite и использовал декодер изображений в Electron |
| TypeScript `npm run typecheck` | Успешно |
| Форматирование `npm run format:check` | Успешно |
| Unit-тесты | 43 пройдено, 2 файла; пропусков и ожидаемых падений нет |
| Интеграционные проверки | 24 сценария пройдено в Electron runtime с настоящей SQLite и файлами |
| Сборка `npm run build` | Успешно для main, процесса данных, preload и renderer |
| E2E из исходного checkout | 2 сценария пройдено; настоящее окно и временные профили |
| Упаковка `electron-builder --linux --dir` | Успешно |
| Те же E2E на `dist/linux-unpacked/history-trainer` | 2 сценария пройдено; это повтор сценариев на другом виде поставки, а не два новых теста |
| Запуск разработки Vite + Electron | Проверено настоящее окно и bootstrap локальной БД через preload/CDP |
| Windows NSIS EXE | Не собирался в Windows; workflow подготовлен, но не запускался |
| Установка/обновление на Windows 10 и 11 | Не выполнялись |

Ключевые подтверждённые свойства: данные остаются после повторного открытия; до второго Enter попытка отсутствует; исправленный текст сохраняется ровно один раз; оценки скрыты до завершения; частичный ответ учитывается в окне 20; снимок эталона не меняется после редактирования материала; JSON переносит связи; полный ZIP восстанавливает историю, настройки, конспект и оригинальные байты изображения; повреждённый архив или медиа не выдаются за успешный результат.

Все объекты и изображения E2E/интеграции — явно синтетические developer fixtures во временных профилях. Снимки окна `test-results/desktop-dashboard.png` и `test-results/desktop-settings.png` относятся к автотесту, а не к настоящей пользовательской исторической базе.

При изображениях в Electron/Linux наблюдаются предупреждение sharp и сообщения GLib. Они не подавлялись. Функциональные проверки JPEG/PNG/WebP прошли; причина и границы выводов описаны в [статусе реализации](implementation-status.md).

Начальный исторический набор 862–1551 и реальные портреты в эти проверки не входили: они ещё не подготовлены. Успешные тесты не объявляют весь продукт и Windows-релиз завершёнными.
